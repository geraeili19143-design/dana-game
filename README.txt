بازی خانوادهٔ دانا — نسخهٔ قابل نصب (PWA)

محتویات: index.html (بازی) ، manifest.webmanifest ، sw.js (کار بدون اینترنت) ، پوشهٔ icons

روش نصب روی گوشی:
۱) پوشهٔ این فایل را روی یک هاست با آدرس https آپلود کنید (مثلاً GitHub Pages، Netlify، Cloudflare Pages یا هر هاست شخصی).
۲) آدرس را در Chrome (اندروید) یا Safari (آیفون) باز کنید.
۳) اندروید: منو ← «نصب برنامه» / آیفون: دکمهٔ اشتراک ← «Add to Home Screen».
بعد از اولین بار باز شدن، بازی بدون اینترنت هم اجرا می‌شود.

توجه: اگر index.html را مستقیم از حافظهٔ گوشی باز کنید، بازی اجرا می‌شود ولی نصب و حالت آفلاین کار نمی‌کند (نیاز به https یا localhost).
